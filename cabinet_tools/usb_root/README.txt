USB root shortcuts
==================
These .bat files stay on the USB stick root for double-click convenience.
Real scripts live under:

  usb_scripts\roulette\
  usb_scripts\shared\
  usb_scripts\slot\

Do not put .ps1 next to these shortcuts — keep companions under usb_scripts.

RAM-CLEAR.cmd runs official maintenance\tasks\ramclear.d (backup + cleanup +
IdleMode), skips ClearWibu so licences stay, then restarts FullStack.
